# Watch Face Format Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A declarative Watch Face Format (WFF) version of Chronology in `wear/wff/`, installable on devices that launch with Wear OS 5+ and eligible for Play Store distribution.

**Architecture:** A code-free APK whose `res/raw/watchface.xml` expresses the orbiting-dial geometry with WFF arithmetic expressions: a 1350×1350 dial group whose `x`/`y` Transforms place its center at `C − (225+orbit)·(sin A, −cos A)` for hour angle `A = 30·[HOUR_0_11_MINUTE]`, and a hand group with the same position Transforms rotated by `A` around its center. The XML (~1500 lines, 2 dial-style variants × ~160 elements) is emitted by a checked-in Python generator, `wear/wff/tools/generate_watchface.py` — edit the generator, never the XML.

**Tech Stack:** WFF version 1 (Wear OS 4+), minSdk 33, plain resource-only Android application module `:wff` (`com.artifact.chronology.wff`), Python 3 stdlib generator.

## Global Constraints

- Canvas 450×450; gabbro reference constants × scale 450/260 = 1.7308.
- Large numerals: font 164, hour inset 48, hour tick 10.4, minor tick 6.9, dot r 5.2. Classic: font 73, inset 24, ticks 5.2/3.5, dot r 3.5. Hand stroke 15.6, round cap. Orbit inset 325.
- 24h labels use `floor()` where the C code truncates toward zero; differs only at the 6-hour tie — documented, accepted.
- Config model (WFF-idiomatic simplification of the Clay set): `dialStyle` list (large default, classic), `themeColor` color list where each option carries `bg text minor` colors (black default, white, blue, green), `handColor` color list (red default, white, black, yellow, blue). Transparent-face/face-color from the Pebble config are folded into `themeColor` — documented omission.
- Numeral positions: static per tick via the Pebble radial-box math with fixed glyph half-dims (12h: per-label digit count; 24h variant under `<Condition>` on `[IS_24_HOUR_MODE]`: 2-digit box for all ticks).
